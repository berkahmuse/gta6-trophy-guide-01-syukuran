**Platinum Road — Leonida Trophy Atlas.** An offline, two-pane trophy atlas for Grand Theft Auto VI (PlayStation 5): all 55 official trophies with a guide for each written in the atlas's own words and citing its sources (the official list on Exophase and PSNProfiles), a six-stage roadmap to the platinum and the nine missable trophies flagged — both built from the official descriptions — plus a tracker whose progress (earned trophies and every PSN counter) is saved in the browser with export/import, kind and grade filters, search, and a spoiler shield that hides unearned story trophies. Original paper-atlas design; no Rockstar artwork or logos.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or serve app/ with any static HTTP server and open index.html
```

To hand the entry in (writes the dossier to `out/`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no build step, no network at run time.
