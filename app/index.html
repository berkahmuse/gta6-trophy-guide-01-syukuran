    Roadmap to the platinum

    Built from the official descriptions: story first, because six named-mission trophies and the choices trophy can be left behind; collectibles and counters in the middle, because they are long; money and heat near the end; 100% and the platinum last. Each stage below shows your live progress from the tracker.

    Missable trophies — do not leave these behind

    Nine trophies are flagged missable, each from its official description alone: six hang on a single named mission (Trust, Break the Bank, Family Matters, DWNFALL, Hi-Jacked, Snow Storm), one on a single location (Catch Me If You Can, at VCIA), one on choices that cannot be unmade (Actions Speak Louder), and one on needing a genuine first failure (Bad Luck, I Guess). Finish each inside its window, or return with mission replay.

      Save, export, settings

      Progress (earned trophies and every counter) is saved in this browser with localStorage as you work. Export it to a file to move it or back it up; import that file to restore it here.

      How the guides cite their sources

      Official names, descriptions and grades follow the PlayStation 5 trophy list as published by Exophase and PSNProfiles; the two agree on every name, description and grade. Every guide is this atlas's own writing, built from those official descriptions, and each trophy's detail pane names its sources beside the guide. Where a description is vague, the guide says so and claims nothing more precise.

      About this atlas

      Platinum Road is an original, unofficial fan guide. It uses no Rockstar Games logo, artwork or screenshots. It works fully offline from its own files.
